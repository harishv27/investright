# InvestRight — Complete Package

This zip contains two things:

## 1. `investright_app/` — the verified, working application

The full source (frontend + backend) with fresh, working dependency setups.
Verification performed on this delivery:

- Backend: rebuilt virtualenv, installed all `requirements.txt` deps cleanly,
  **11/11 pytest tests pass**, live server smoke-tested end-to-end (signup →
  profile → risk assessment → dashboard), capacity guardrail confirmed
  working correctly.
- Frontend: reinstalled `node_modules`, **production build succeeds**,
  lint reduced to 0 errors (fixed an empty-catch-block warning in
  `frontend/src/api/client.js`).

To run it yourself:

```bash
# Backend
cd investright_app/backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # edit JWT_SECRET etc. before real use
uvicorn app.main:app --reload --port 8000

# Frontend (second terminal)
cd investright_app/frontend
npm install
cp .env.example .env
npm run dev
```

See `investright_app/README.md` for full documentation, API routes, and the
production checklist.

## 2. `results_package/` — everything for the research write-up

Start with **`results_package/RESEARCH_RESULTS.md`** — it's the main report,
covering:

1. Application verification results
2. Table IV reproduction (functional validation, N=240)
3. Fig. 2 reproduction (risk category distribution) — matches the paper
   almost exactly, plus a new finding about calibrated-band overcorrection
4. Table V reproduction (recommendation distribution)
5. Retrieval experiment (lexical_rag vs. full_history vs. baselines)
6. Risk-band calibration parameters
7. Technology stack table
8. Concrete suggested next steps for strengthening the paper

Everything in that report is backed by real files in the same folder:

- `results_package/figures/` — 6 PNG charts, ready to drop into the paper
- `results_package/tables/` — every table as both `.md` and `.csv`
- `results_package/raw_data/` — the underlying JSON/CSV data behind every
  number (including the 240 raw synthetic profiles used)
- `results_package/scripts/` — the exact, runnable Python scripts that
  produced every number and figure above (no API key or network needed)
- `results_package/ORIGINAL_RESULTS.md` — the project's pre-existing
  RESULTS.md, kept for reference

Every number in `RESEARCH_RESULTS.md` was generated by running these scripts
against the actual production code in `investright_app/backend/app/` — not
hand-typed or copied from the paper — so it can be independently
re-verified or re-run with different seeds/sample sizes.
